# Post-build plan fidelity audit

Plan Audit: grade the finished build against the plan's ORIGINAL acceptance criteria—the frozen `plan-baseline:` commit—not criteria written or edited mid-build. Report every gap; fix nothing yourself.

STAGE 0 — BASELINE: `git log --reverse --grep='^plan-baseline: <plan-path>$' --format=%H <target-branch>..HEAD | head -n1` (repo-relative path; target = the branch this merges into, else master/main); the EARLIEST is the exam, and every later plan-baseline commit is a goalpost change (APPROVED only if its message or the plan cites the user's approval). None on the branch → use the most recent in `git log --grep=… HEAD` and say it predates the branch. No baseline at all, plan not in git, or no criteria → STOP and ask (give the freeze command `git add <plan-path> && git commit --allow-empty -m "plan-baseline: <plan-path>" -- <plan-path>`, and warn that freezing after the build can't reveal earlier edits); never substitute the current plan or write criteria yourself. Extract criteria verbatim from `git show <sha>:<plan-path>` with priority (P0/P1/P2) and check type; no priority = P0; no check type = automated if a command is named, else manual; assign AC-n if unnumbered.
STAGE 1 — GOALPOST DIFF: compare baseline vs current criteria, quoting both. STRICTER/EQUIVALENT → note. WEAKER/CHANGED/REMOVED/ADDED → MOVED, marked APPROVED (cite where the user approved) or UNAPPROVED. Always grade against the baseline text.
STAGE 2 — BLIND AUDIT: spawn one fresh (non-fork) agent with only the baseline criteria, the branch diff (`git diff <target-branch>...HEAD` + in-scope working tree), and the repo. Per criterion: MET/PARTIAL/UNMET/UNVERIFIABLE + citations. Default UNMET. MET needs a citation (file:line quote, or command + output excerpt); uncited = evidence ≤5 = not MET; automated P0 MET needs a test run. Manual/production-only → UNVERIFIABLE + exact steps; a P0 one becomes NEEDS SIGN-OFF until the user confirms. Unknown test command → UNVERIFIABLE. Then re-run every cited P0 command yourself—only the criterion's own check or test/read-only commands, never anything that deletes, resets, installs, pushes, or writes outside the test run. A citation that doesn't reproduce → UNMET.
STAGE 3 — MUTATION SPOT-CHECK (P0 automated MET only): only on a tracked file with no staged/unstaged changes (`git ls-files --error-unmatch <file>`, `git diff --quiet -- <file>`, `git diff --cached --quiet -- <file>`). Record its sha256, break the satisfying line, run the proving test, restore with `git checkout -- <file>`, and confirm the sha256 matches (mandatory even if the test crashed; mismatch → STOP and name the file). Red → MET stands. Green → PARTIAL. Can't run → "mutation: not run (reason)", flagged "coverage unproven".
STAGE 4 — REVERSE TRACE: map each changed file/hunk to an AC or phase (the plan file is exempt). Unmapped → SCOPE-CREEP (P2; P1 if it touches a trust boundary).
STAGE 5 — INTENT CHECK: does the MET set achieve the plan's stated goal? List letter-vs-spirit gaps.
STAGE 6 — REMEDIATION PLAN (only if gaps): per gap, P0 first—AC id, baseline criterion verbatim, gap evidence, proposed fix, verify = the original check. Present it and STOP for approval.
STAGE 7 — HANDOFF: on approval, fix per ::F with each criterion verbatim as its validation criteria. Recommend re-running ::PA afterwards; don't loop automatically.

REPORT: fidelity matrix (AC, priority, verdict, citation, mutation) + verdict × priority counts (no weighted score); moved goalposts; scope creep; intent gaps; remediation plan; verdict—NOT DONE if any P0 is UNMET/PARTIAL, else NEEDS SIGN-OFF if any P0 needs sign-off or has an UNAPPROVED move, else DONE; footer with agent count + wall time.

RULES:
- Confidence anchors: 1-3=guessing, 4-6=informed but unverified, 7-8=verified by reading code, 9-10=verified with test run
- Zero net edits during the audit (Stages 0-6): tracked content, the index, and pre-existing untracked files end byte-identical; test caches don't count
- The auditor reports; it never fixes. A missing baseline or criteria is a STOP, not a guess.
